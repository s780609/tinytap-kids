# TinyTap 兒童樂園

專為 1～3 歲幼兒設計的安全觸控遊戲 PWA，支援離線遊玩、可安裝至手機桌面。

## 功能特色

- 完整 PWA 支援（Android Chrome / PC Chrome 可安裝為獨立 App）
- 離線可用（Service Worker 快取所有資源）
- 全螢幕 standalone 模式
- 大觸控區域、鮮豔色彩、無失敗懲罰、即時正面回饋
- 家長設定（長按右上角）：預設模式、音量、遊玩計時提醒、釣魚的點點捲線輪
- 返回鍵要按住約 0.8 秒才會返回（外圈進度環填滿），寶寶亂拍不會跳出遊戲
- 可完全離線遊玩：Service Worker 安裝時就預先快取所有頁面與音效，搭飛機前打開一次 App 即可
- 全介面中文化

## 遊戲模式

### 寶寶模式（適合 1 歲）

- **氣球點點樂** — 點擊畫面任何地方爆出彩色氣球 + 粒子噴射 + 音效回饋，點空白處也有小火花
- **寶寶鋼琴** — 兒童玩具鋼琴：Do 到高音 Do 八個彩虹白鍵加五個黑鍵，按下去鍵會沉下去、飄出彩色音符；手指按著滑過琴鍵可以刷鍵，支援多指。上方有自動彈兒歌按鈕（小星星、小蜜蜂、倫敦鐵橋），彈奏時對應的鍵會亮起來，再按一次停止
- **躲貓貓** — 四個大藏身處（草叢、門、禮物盒、窗簾），點一下打開，動物跳出來「哇！」並叫一聲，過一會兒自己躲回去，再換一隻新動物藏起來
- **擦窗戶** — 畫面蓋著一層霧，手指隨便抹就擦掉霧、露出底下的動物和風景，擦掉約三分之二就整片放晴、喊出動物名字並叫一聲，接著重新起霧換下一張
- **動物鍵盤** — 六個動物鍵由低到高是大象、牛、獅子、狗狗、貓咪、鴨子，按下去動物叫聲會變成那個鍵的音高（Do Re Mi Fa Sol La），剛按到的動物會在舞台上跳出來

### 幼兒模式（適合 3 歲）

- **畫畫板** — 全螢幕 Canvas 繪畫，8 色色盤、3 種筆刷、橡皮擦、印章（星星/愛心/貓咪/小狗/花朵/蝴蝶）、撤銷、清除、背景色切換。內建描繪圖線模板（小馬/兔子/迷你豬），淺灰虛線引導小朋友沿線描繪
- **記憶翻牌** — 4x3 翻牌配對遊戲，6 對可愛動物 SVG，全部配對完成有慶祝動畫
- **數一數** — 隨機顯示 1～5 個水果（蘋果/香蕉/葡萄/橘子/草莓），點選正確數字
- **賽車** — Canvas 跑道自動捲動，中央方向盤觸控轉動控制車子平滑移動。3-2-1 倒數開始、2 分鐘計時、目標 30 金幣。吃到金幣會飛向右上角收集欄。撞到石頭會扣一顆愛心，撞 3 次就結束
- **玩沙沙** — 側視圖沙盤，沙子是一粒一粒的格子沙（falling sand 細胞自動機），會往下掉、堆太陡就滑落。手指可以推沙、挖沙堆成沙丘；水桶倒出的沙粒會真的落下堆積；壓平板可以把沙壓平；城堡 / 波浪 / 小山是裝滿沙倒扣的模具，點在沙面上再拿起來就留下形狀，模具壓出來的沙是紮實的、不會自己崩塌
- **釣魚** — 釣魚池裡有鯊魚、鯉魚、河豚、烏龜、章魚、螃蟹和輪胎、舊靴子、鐵罐，偶爾會出現閃閃發亮的稀有獵物（金色小魚、鯨魚、美人魚、寶箱），釣到有彩帶慶祝。每次進來的數量、組合與深度都隨機；魚會左右也會上下游動，每隔幾秒會有新的魚從池邊游進來，池子滿了舊的會游走。直接點池塘，點哪裡鉤子就丟到哪裡，落水會濺起水花；點到魚牠會跳一下、吐泡泡。魚咬餌時浮標被拉下去、跳出「！」、手機震一下，接著出現捲線輪，手指在輪子上畫圈收線，每種魚圈數不同（烏龜、螃蟹 2 圈，鯊魚、鯨魚力氣大要 5 圈，釣竿會彎、畫面會晃），河豚上鉤會鼓成一顆球、章魚會噴墨汁。家長設定可以打開「點點捲線輪」，還不會畫圈的小小孩連點輪子也能收線。釣到魚會用語音說出名字並飛進左邊的水桶；點水桶可以看釣到什麼、把魚放生回池塘，或打開水族箱看牠們游來游去（點魚會跳起來）。撿到的垃圾會掉在草地上，拖進右下角的回收桶。左上角的📖魚類圖鑑記錄釣過的種類（沒釣過是剪影），存在 localStorage，全部收集完有慶祝；上方的任務卡會出「釣三隻螃蟹」、「撿兩個垃圾」之類的小任務練習數數。右上角可以換場景：晴天、黃昏、夜晚（螢火蟲、月亮倒影）、下雨、春天（櫻花）、秋天（落葉）、冬天（下雪），每次進來隨機一種
- **太空彈珠台** — 太空主題彈珠台：霓虹檯面、星球彈射器、星星通道燈、發光拖尾的彈珠。右下角有彈簧拉桿，彈珠等發射時點一下右半邊畫面，右下方會跳出放大版拉桿，在裡面往下拉再放開就把彈珠打上去，拉越深力道越大；按擋板正下方的 ◀ ▶ 按鈕控制左右擋板，撞星球得分、四顆星星全亮有大獎，五顆球用完結算分數；剛進檯面 8 秒內掉球會免費還一顆。檯面參考 Space Cadet 的玩法：擋板上方有三角彈射板、兩側有出球道與回球道（出球道的救球燈亮著時會把球彈回來一次）、右牆有三個落靶、中央黑洞會把慢速的球傳送到上方白洞、左側有 U 形坡道（上層）。任務依序是「打倒三個靶 → 進黑洞 → 衝上坡道」，黃色箭頭會指著現在該打的目標，完成後有大獎並升一級
- **夜市彈珠台** — 台灣夜市那種沒有擋板的彈珠台：黃色機身、彩虹邊框、粉紫色檯面、跑馬燈和燈籠。先從機台下方的珠盤拿一顆彈珠，拖到右上方的投珠口放開，彈珠會自己掉到右下角的拉桿上；彈珠在拉桿上等發射時，在畫面任何地方按住往下拖再放開，就把彈珠打上去，拉越深力道越大；力道不夠會滑回拉桿，可以重打、不扣球。彈珠穿過釘子陣後掉進底部七格之一，依格子得分（中間 100 分最高），掉進去的彈珠會留在格子裡疊起來；十顆打完結算總分
- **動物樂團** — 節奏遊戲：企鵝 🐧、貓咪 🐱、狗狗 🐶 在夜空舞台上組樂團，三條軌道對應三隻動物。星星照著兒歌旋律往下掉，掉到發光的線上時點下面的大圓按鈕（或軌道任何地方），長長的星星要按住到尾巴；判定很寬鬆，太早按不扣分，判定顯示「超棒！/ 不錯！/ 差一點」，旋律一直照譜播放、打中多一聲 tick。五首經典兒歌（小星星、兩隻老虎、小蜜蜂、倫敦鐵橋、王老先生有塊地），兩種難度 🐢 慢慢 / 🐰 快快；有分數、連擊（每 10 連擊動物一起跳），結算給 1～3 顆星與評級，各歌各難度的最佳紀錄存在 localStorage。支援多指與鍵盤 A/S/D、← ↓ →，切到背景會自動暫停

## 技術架構

| 項目 | 技術 |
|------|------|
| 框架 | Next.js 16 (App Router) |
| PWA | Serwist (@serwist/next) + 手動 SW 註冊 |
| 樣式 | Tailwind CSS v4 |
| 音效 | Web Audio API 合成 + .wav 檔案 |
| 動畫 | CSS Animations + Canvas 粒子特效 |
| 圖形 | Inline SVG React 元件 |
| 狀態 | React Context + useState |
| 觸控 | Pointer Events API（統一觸控與滑鼠） |

## 開始使用

```bash
# 安裝依賴
npm install

# 開發模式
npm run dev

# 單元測試（沙子物理模組，使用 Node 內建 test runner）
npm test

# 建置
npm run build

# 預覽 production（PWA 安裝需在此模式測試）
npm start
```

> 注意：因 Serwist 尚未支援 Turbopack，dev 和 build script 已內建 `--webpack` 旗標。

## PWA 安裝測試

1. 執行 `npm run build && npm start`
2. Chrome 開啟 `http://localhost:3000`
3. 網址列右邊出現安裝圖示，或到 `⋮ → 安裝 TinyTap 兒童樂園`
4. DevTools → Application → Service Worker 確認已註冊
5. 斷網後重新整理，確認可正常遊玩
6. Android Chrome 點選「新增到主畫面」可安裝為獨立 App
